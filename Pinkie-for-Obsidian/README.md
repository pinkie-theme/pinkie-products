## ✨ Super Cute Features ✨

- 🌸 **Sweet Pastel Palette**: A lovely white-pink background paired with deep pink accents that are super gentle on your eyes. It feels like writing in a fluffy pink diary! ☁️
- 🐈 **Flat & Minimalist UI**: We completely removed the distracting UI elements like status bars, borders, and window frames, bringing you an absolute clean and friendly interface.
- 🎨 **Beautiful Markdown**: Headings, links, and text formatting are beautifully re-tuned with soft pastel colors.

## 🎀 How to Install

1. Place the `Pinkie for Obsidian` folder inside your `.obsidian/themes/` directory.
2. Open Obsidian Settings > Appearance.
3. Under Themes, select **Pinkie for Obsidian**.
4. Yay! Enjoy your super cute new vault! 🎉
